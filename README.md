
# RUTUBE без рекламы

Одна папка — два способа установки:

- **Chromium-браузеры** (Яндекс Браузер, Chrome, Edge, Opera, Vivaldi, Brave) — расширение с кнопкой и значком на панели браузера;
- **Firefox** — тот же скрипт в виде userscript через Tampermonkey.

Что делает в обоих случаях:

- убирает рекламные блоки и баннеры на всех страницах rutube.ru;
- вычищает рекламные поля из ответов API и отдаёт пустой ответ на рекламные запросы;
- пропускает видеорекламу: глушит звук, ускоряет и перематывает вставку, потом возвращает громкость и скорость;
- **скрывает уведомление** RUTUBE «Блокировщик рекламы может помешать правильной работе плеера»;
- показывает **кнопку «Реклама выключена / Реклама включена»** внизу справа;
- запоминает выбор — после перезагрузки страницы, браузера и компьютера ничего заново нажимать не нужно.

## Установка: один раз, нажать «Инструкция»

1. Дважды щёлкните **`Инструкция.bat`**.
   Откроется папка с файлами и окно с шагами: скрипт сам определит ваш браузер и положит нужную ссылку в буфер обмена.
2. `Ctrl+V` в адресную строку браузера → `Enter`.
3. Дальше по шагам из окна — они разные для Chromium и Firefox, ниже подробно.

После установки файл `Инструкция.bat` больше не нужен.

### Chromium: три шага

1. Открыть страницу расширений (ссылка уже в буфере).
2. Включить **Режим разработчика** → **Загрузить распакованное расширение**.
3. Выбрать папку `rutube-no-ads` — ту, где лежит `manifest.json`.

Значок появится на панели браузера, кнопка — на страницах RUTUBE. Щелчок по значку тоже переключает рекламу.

Почему нельзя совсем без шагов: Chromium не разрешает ставить расширение из папки скриптом, только вручную через свою страницу расширений.

### Firefox: четыре шага

1. Открыть ссылку из окна (уже в буфере) — это Tampermonkey в официальном каталоге Mozilla → **«Добавить в Firefox»**.
2. Значок Tampermonkey → **«Панель управления»** → вкладка **«Утилиты»** → **«Импорт из файла»**.
3. Выбрать `firefox\rutube-no-ads.user.js`.
   Если импорт не сработал: **«Создать новый скрипт»**, удалить шаблон, вставить содержимое файла, `Ctrl+S`.
4. Открыть rutube.ru.

Почему для Firefox отдельный файл: Firefox принимает только подписанные расширения из своего каталога, установить папку или самодельный `.xpi` навсегда нельзя (только временно, до перезапуска — это не вариант для учителя). Поэтому там используется userscript: он ставится из официального каталога и живёт постоянно.

Честная разница: в Firefox userscript **не может запретить сам запрос** видео-рекламы, поэтому вставка всё же стартует — но сразу глушится и перематывается (звука и картинки рекламы фактически нет). В Chromium рекламный запрос блокируется на уровне сети и вставка не начинается вовсе. Баннеры и остальная реклама убираются одинаково.

## Ссылка на страницу расширений — для любого браузера

У каждого браузера свой адрес, и скрипт подставляет нужный автоматически:

| Браузер | Адрес |
| --- | --- |
| Яндекс Браузер | `browser://extensions` |
| Google Chrome | `chrome://extensions` |
| Microsoft Edge | `edge://extensions` |
| Opera | `opera://extensions` |
| Vivaldi | `vivaldi://extensions` |
| Brave | `brave://extensions` |
| Firefox | не нужен — установка через Tampermonkey |
| незнакомый Chromium-браузер | `chrome://extensions` |

Если адрес угадан неверно, откройте меню браузера → «Дополнения» / «Расширения»: страница та же.

## Как пользоваться кнопкой

Внизу справа на любой странице rutube.ru:

- **«Реклама выключена»** (зелёная точка) — блокировка работает;
- нажали — **«Реклама включена»** (красная точка);
- нажали ещё раз — снова выключена.

В Chromium то же делает щелчок по значку расширения; при выключенной блокировке на значке видна красная пометка `OFF`.

После переключения обновите страницу (F5): уже отправленные запросы не переигрываются, новые пойдут по новому правилу.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `Инструкция.bat` | Открывает папку и подсказку под ваш браузер, копирует нужную ссылку |
| `tools/show-install-hint.ps1` | Определяет браузер по реестру Windows и показывает шаги |
| `manifest.json` | MV3-манифест: права, значки, сетевые правила, скрипты |
| `background/service-worker.js` | Хранит настройку, включает/выключает сетевую блокировку, обрабатывает клик по значку |
| `content/bridge.js` | Связывает страницу с фоновым скриптом в обе стороны |
| `content/main-world.js` | Основная логика: кнопка, перехват запросов, вычистка полей, авто-пропуск, скрытие блоков и уведомления |
| `firefox/rutube-no-ads.user.js` | Тот же скрипт, собранный для Tampermonkey (генерируется) |
| `tools/build-userscript.mjs` | Собирает userscript из `content/main-world.js` |
| `rules/ads.json` | 10 сетевых правил блокировки рекламных хостов |
| `icons/icon16.png` … `icon128.png` | Значок расширения и кнопки на панели |
| `tools/make-icons.ps1` | Перерисовывает значок |
| `test/ad-filter.test.mjs` | 17 тестов логики фильтрации и переключения |

Папка `_metadata` создаётся самим браузером при загрузке расширения — её не нужно трогать.

## Разработка

```bash
node --test test/ad-filter.test.mjs
node --check content/main-world.js
node --check content/bridge.js
node --check background/service-worker.js
node tools/build-userscript.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File tools/make-icons.ps1
```

После правок в `content/main-world.js` userscript нужно пересобрать: `node tools/build-userscript.mjs`.

## Ограничения

- Chromium-расширение — только Chromium 111+; Firefox — 128+ (Tampermonkey ставится на любую актуальную версию).
- Установка расширения из папки — вручную, один раз (ограничение Chromium).
- В Firefox видео-реклама пропускается, а не блокируется на уровне сети.
- Уведомление RUTUBE скрывается по тексту «блокировщик рекламы»: если платформа переформулирует его, правило нужно дополнить в `NOTICE_TEXT_RE` (`content/main-world.js`).
- Если RUTUBE начнёт отдавать рекламу с того же хоста, что и видео, обновите `AD_HOSTS` и `rules/ads.json`, затем нажмите «Обновить» на карточке расширения и пересоберите userscript.
- Блокировка рекламы на своём устройстве законна, но лишает платформу дохода; для постоянного использования у RUTUBE есть платная подписка без рекламы.
